# **Deskripsi Projek**
Proyek ini bertujuan untuk menganalisis kebiasaan mendengarkan musik pribadi berdasarkan data histori pengguna Spotify. Visualisasi dibuat menggunakan Power BI untuk menampilkan informasi favorit pengguna, pola waktu mendengarkan musik, dan interaksi dengan musik.

# **Tujuan Projek**
  - Mengidentifikasi artis, lagu, dan genre yang paling sering didengarkan
  - Menemukan waktu favorit untuk mendengarkan musik (jam, hari, bulan)
  - Mengetahui seberapa sering pengguna melewati lagu (skip), menggunakan mode shuffle, atau menyelesaikan lagu

# **Struktur Dashboard**
  1. How do you listen to music overall?
  2. Who do you listen to the most?
  3. When do you listen into music the most?
  4. How do you interact with your music?
