# **Overview**
This project is a data visualization dashboard that provides insights into personal Spotify listening history. The analysis includes listening trends, top songs and artists, and behavioral patterns over time.
The visual dashboard is designed using Power BI, with data sourced from exported Spotify listening history and enriched via the Spotify Web API for enhanced visuals, such as artist photos and album covers.

# **Objectives**
- To explore and understand personal music listening behavior
- To apply data cleaning, transformation, and visualization techniques
- To experiment with enriching raw data using APIsu

# **Struktur Dashboard**
  1. How do you listen to music overall?
  2. Who do you listen to the most?
  3. When do you listen into music the most?
  4. How do you interact with your music?

# **Tools & Technologies**
- Power BI for data visualization
- Spotify Web API for retrieving images and metadata
- Python for API calls
